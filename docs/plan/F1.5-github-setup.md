## Langkah (urut, 5 menit)
1. `git init` di `rev-bumi-os/` (jika belum), `git add .`, `git commit -m "chore: initial commit REV Bumi OS monorepo"`.
2. `gh repo create rev-bumi-os-v2 --private --source=. --remote=origin` (atau manual `git remote add origin https://github.com/<user>/rev-bumi-os-v2.git`).
3. `git push -u origin main` (pastikan `sbp_`, `Ucihavieri11`, `anonKey` tidak ter-commit — scan `grep -r sbp_`).
4. Buat `.github/workflows/ci.yml`:
   ```yaml
   name: ci
   on: [push, pull_request]
   jobs:
     verify:
       runs-on: ubuntu-latest
       steps:
         - uses: actions/checkout@v4
         - uses: actions/setup-node@v4
           with: { node-version: 20, cache: npm }
         - run: npm ci
         - run: npm run lint
         - run: npm run check-types
         - run: npm run build --workspace=web
         - run: node apps/web/e2e17-mobile-rls.cjs
           env: { SUPABASE_URL, SUPABASE_ANON_KEY } # dari GitHub Secrets
   ```
   Secrets: `SUPABASE_URL`, `SUPABASE_ANON_KEY` (anon, bukan `service_role`).
5. Proteksi `main`: Settings → Branches → Require PR before merging, require `verify` pass. Builder hanya push `feat/*`.
6. Dokumentasi: tambah badge CI di `README.md`, update `ROADMAP.md:108` catat repo URL.
